# 💬 FullStack Realtime Chat

Um sistema de chat em tempo real desenvolvido com **NestJS**, **Next.js**, **Socket.IO** e **Prisma ORM**, permitindo comunicação instantânea entre usuários com persistência de mensagens em banco de dados.

---

# 🚀 Tecnologias Utilizadas

## 🔹 Front-end
- Next.js
- React
- TypeScript
- Socket.IO Client
- CSS3

## 🔹 Back-end
- NestJS
- WebSocket Gateway
- Socket.IO
- Prisma ORM
- SQLite

---

# ✨ Funcionalidades

✅ Chat em tempo real  
✅ Comunicação via WebSocket  
✅ Persistência de mensagens no banco de dados  
✅ Histórico carregado automaticamente ao conectar  
✅ Indicador de usuários conectando/desconectando  
✅ Estilização condicional de mensagens  
✅ Interface moderna com tema futurista/neon  
✅ Estrutura FullStack separada em Front-end e Back-end  

---

# 📸 Funcionalidades Implementadas

## 🔔 Indicador de Presença
O sistema exibe mensagens quando:
- um usuário entra no chat
- um usuário sai do chat

---

## 💬 Mensagens em Tempo Real
As mensagens são transmitidas instantaneamente utilizando:

- Socket.IO
- WebSockets
- NestJS Gateway

---

## 🗄️ Persistência com Prisma ORM
Todas as mensagens enviadas:
- são salvas automaticamente no banco SQLite
- permanecem salvas mesmo após reiniciar o sistema

---

## 🎨 Interface Futurista
A interface possui:
- fundo escuro
- efeitos neon
- glassmorphism
- animações suaves
- mensagens diferenciadas visualmente
